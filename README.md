## **Projects**

- **Bachelor Thesis:** *Cation-dependant aggregation of polyQ β sheets - Ion Behavior in Protein Systems: A Biophysical Approach Using MD-Simulations and Poisson-Boltzmann Theory*.
      Using *GROMAX* and *MATLAB* within the Continuum Theory framework, we found that kosmotropic ions enhance distinct regions of negative osmotic pressure in a system of two PolyQ β-sheets driving  polyQ aggregation which is believed to be emergent for neurodegenerative diseases like Alzheimer.

- **Monte Carlo Simulations:** simulating the **Ising Model** Phase-Transition for liquid-gas and ferromagnetic systems. Different approaches were followed: single spin flip Hastings algorithm, Swendsen-Wang Cluster algorithm with Improved Estimators in Fortuin and Kasteleyn representation. Analysis on Finite Size Scaling (FSS) and Critical Exponents within the framework of Renormalization and Universility.

- **Master Thesis:** *Automated Generation of FE Meshes - LSF CLuster automation*, in cooperation with Infineon Technologies Austria AG
      Using **MTEX**, **Neper** and **COMSOL's JAVA API** and Model Builder I was able to build a pipeline feeding industrial copper **EBSD data** for the statistical representation of polycrystaline material. The models are used for **Finite Element simulations** and verified against Viscoplasticity and Creep simulations.
